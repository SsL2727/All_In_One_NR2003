Launch NR2003 through RaceLab
All In One NR2003's Launch NR2003 starts the game with RaceLab's SpinMod.dll (AI racecraft, tire failures, crash panels or soft body, traffic yield, drafting rows, allies / rivals, Career). The shim, bridge and overlays start as always, and NR2003 Background (if on) attaches to the game as soon as it starts. Starting the game from RaceLab's own window instead loads RaceLab but not All In One NR2003's overlays.
RaceLab folder—
Game EXE
RaceLab only loads into its own game builds and they must keep their names, so the game then runs as NR2003_RaceLabV2.exe or NR2003_MS.exe. All In One NR2003's mods (Race Control, AIMOD, AI Enhanced, RaceVision, the overlays) find the game under those names too. Pick the build that matches your rend_dxg.dll (RaceLab's Game EXEs\Choosing a game EXE.txt); a build not in the game folder yet is copied there from Game EXEs. Start the game with All In One NR2003's Launch NR2003 so the shim, bridge and overlays start with it.

    
Renderer—

    

    
Soft body checks rend_dxg.dll as a pair with the game EXE. Switching backs up your own rend_dxg.dll first (rend_dxg.dll.steelfire-original in the game folder, made once and never overwritten) and Restore original puts it back. Both are checked by SHA-256. Close NR2003 before switching.

  


  
Body damage

    

    
RaceLab panels: detachable panels and wheels for Original Cup, 2003WC_sng, 2005NCS_sng, COT, cup2000, ncts09, nnc, oreilly2026_ultra, truck2026_ultra. A soft-body mode is for one exact installed series: make that series active in NR2003 first (and exit the game normally so it saves), then pick its mode here. Close the game before switching modes.

  


  
All In One NR2003 alongside RaceLab

    

    
While RaceLab runs in the game, All In One NR2003 never steers the same cars twice: with RaceLab's racing lines on, Superspeedway Lines and AI Enhanced's tandem / MultiGroove step aside; with its allies / rivals on, AIMOD's racing intensity and rivals step aside (every driver gets his own aggression back). AIMOD's pit strategy, Race Control, the TV director, the season tracker and the overlays keep running. RaceLab's Career and All In One NR2003's season tracker each keep their own records.

    

  










  
Panels, wheels and pit repairs

  
Soft body tuning

    
Each region: contact deformation % (more = more crush) and fastener strength % (more = stays on longer). 100 / 100 is the fitted response; 25-250 each. A front bumper that crumples right but comes off too soon: try 100 / 125. Shared by every soft-body profile (CupPanelTuning.ini); restart the game after changing.

RaceLab careers

  
RaceLab's Career runs in the game (Inbox, Garage, sponsors, money). Its schedules come from RaceLab's Schedule Creator (Open RaceLab's launcher). Saves are in RaceLabCareer beside RaceLab.
